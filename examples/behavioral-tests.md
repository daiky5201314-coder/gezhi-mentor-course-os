# GEZHI MENTOR COURSE OS 行为测试

这些测试检查可观察行为，不要求固定措辞。测试时应给Skill最小必要资料，并在临时输出中运行，避免污染课程资产。

## Test 1｜重新设计院校篇

**输入**

> 帮我重新设计院校篇课程。

**预期行为**

- 先读取项目上下文、完整60课和164映射。
- 检查院校篇与专业篇、测评篇、实操篇等边界。
- 列出院校篇每课不可替代能力、递进和可能重复。
- 输出课程体系设计方案并停在Checkpoint 1。
- 不直接研究成稿，不生成逐页PPT内容稿。

**失败条件**

- 直接写PPT页。
- 只看院校篇，不检查其他七篇。
- 改变知识点主讲归属却不说明。

## Test 2｜设计院校篇第06课

**输入**

> 开始设计院校篇第06课。

**预期行为**

- 准确识别第06课为“真正看懂一所大学：格知院校六维评价模型”。
- 读取第05、06、07课，并检查第08—12课如何调用该模型。
- 找到本课对应的 YX-05 至 YX-09 及完整原知识点。
- 输出“必须讲／可以引用／禁止展开”边界卡。
- 明确本课能力目标和课程设计，停在Checkpoint 1。

**失败条件**

- 直接生成最终PPT稿。
- 重讲第05课院校身份或抢讲第09—12课具体院校。
- 只有六个维度名称，没有研究方法与判断产出。

## Test 3｜理解“太理论”

**前置状态**

Checkpoint 1方案已给出。

**输入**

> 太理论了，增加真实案例和就业判断。

**预期行为**

- 不只改措辞。
- 诊断缺少的是案例、证据、普通学生结果、就业验证、咨询动作还是工具。
- 增加有条件的真实或标明合成的案例。
- 增加招聘、毕业去向、学历门槛等与本课边界一致的就业判断。
- 保持就业不是唯一答案，并检查是否抢讲其他课程。
- 返回修订后的相关模块和影响说明，而不是无意义重写全部内容。

**失败条件**

- 只加“就业很重要”。
- 编造企业、数据或学生结果。
- 每个模块都强行加入就业倒推。

## Test 4｜生成逐页内容稿

**前置状态**

课程设计与完整课程内容蓝图均已确认，或用户明确授权同一轮继续完成中间蓝图与最终稿。

**输入**

> 课程内容确认，生成PPT内容稿。

**预期行为**

- 读取PPT内容稿规范。
- 输出完整逐页稿，不制作PPTX。
- 每页含页码、标题、核心观点、完整PPT正文和表达建议；案例/数据、讲解重点、来源按需出现。
- 不使用“此处加入案例”等占位语。
- 页数由课程逻辑决定。
- 完成五项内容稿质量测试和逐页检查。

**失败条件**

- 只输出“P01讲什么”的大纲。
- 直接制作PPT文件。
- 默认扩写成长篇逐字稿。
- 固定30页或机械套齐所有页面类型。

## Test 5｜局部替换第12页

**前置状态**

已有完整逐页内容稿。

**输入**

> 第12页太普通，换掉。

**预期行为**

- 先判断第12页的教学任务、与第11和13页的关系。
- 诊断“普通”来自常识、重复、缺证据、缺判断或叙事停滞。
- 决定删除、合并或替换，并提供完整的新第12页。
- 更新受影响的页码、交叉引用、来源或转场。
- 只修改必要范围并汇报影响。

**失败条件**

- 只换标题或润色措辞。
- 无视前后逻辑。
- 重写整门课。

## Test 6｜课程产出不自动变成页面

**前置状态**

院校篇第05课内容蓝图已确认。课表写有课程产出《高校身份识别框架》，但核心内容只有高校身份类别、主管关系、院校类型及官方标签。

**输入**

> 生成完整逐页内容稿。

**预期行为**

- 页面从本课核心问题、核心内容和已确认蓝图推导；可讲清身份判断，但不因为“课程产出”栏出现框架就自动制作“《高校身份识别框架》五件套”。
- 不自行发明“10分钟身份定位SOP”、定位卡、迁移作业或额外工具；只有课表核心内容或用户明确要求时才加入。
- 不机械增设“迁移与边界”页或“本课带走什么”总结页；边界可融入真正相关页面。
- 事实来源与核验留在非上屏备注，不自动设置“来源与核验表”PPT页。
- 外部检索只核实课表范围内的事实，不因搜到新信息扩课。

**失败条件**

- 把课表“课程产出”名称直接改写成PPT工具页。
- 连续出现工具包、迁移任务、总结页、上屏来源表等模板化尾页。
- 为填充页数引入课表没有要求、用户也未确认的工具或任务。

## Test 7｜规划师能力而非额外产出

**输入**

> 院校篇这一课怎样设计得更贴近格知规划师的真实咨询？

**预期行为**

- 先核对具体课次及课表边界；不清楚是哪一课时先确认，不凭“院校篇”扩成整套咨询流程。
- 将本课目标表述为一项可观察的规划师工作能力：面对什么服务问题、依据什么信息、如何判断或解释、何时保留结论。
- 用该能力选择案例、证据和讲解深度，不增加课表之外的主题。
- 不为了体现业务属性而自动制作定位卡、咨询SOP、家长话术包或方案交付物。

**失败条件**

- 只把“规划师”写进标题，正文仍是百科介绍。
- 要求本课完成从学生画像到志愿交付的全流程。
- 以“贴近业务”为由新增课表未要求的工具或页面。
