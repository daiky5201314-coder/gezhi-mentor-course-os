# 课程架构与研发工作流

## 1. 课程体系定位

任何单课都不是孤立文章。先把它放回八篇60课系统，回答：

- 前面已经建立了哪些知识、方法和工具？
- 本课删除后，导师会缺少哪一种能力？
- 本课哪些知识拥有唯一主讲权？
- 哪些内容只能调用，不得重新教学？
- 后课需要从本课接走什么？
- 本课最终必须产生什么可观察、可考核的结果？

课程名称不是能力目标。“了解、熟悉、掌握”也不是能力目标。用可执行动词描述：能识别、能比较、能核验、能判断、能解释、能制作、能复核、能处理。

能力目标必须落到本课负责的具体咨询问题：学员面对什么服务问题、依据什么信息、如何判断或解释、何时不能下结论。不要求每课覆盖完整咨询流程，不拼装整套规划服务。

## 2. 权威顺序与版本冲突

1. course-system-60.md 与 knowledge-map-164.md 决定编号、名称、篇章、唯一主讲归属和边界。
2. GEZHI_PROJECT_CONTEXT.md 决定格知定位、研发原则和长期标准。
3. 已完成课程稿与PPT只作表达、节奏、教学方式和颗粒度参考。
4. 企宣与手册只作业务与品牌参考；动态数字需要重新核验。

发现冲突时明确指出冲突、采用的权威版本及影响。不得把旧课件内容静默移入新编号。

## 3. 全局检查

### 体系设计

重构一篇课程时，先列出：

- 本篇培养目标
- 本篇每课的唯一能力
- 本篇内部递进关系
- 与其他七篇的输入、输出和边界
- 164知识点的主讲归属变化
- 可能造成重复或能力缺口的位置

未经用户确认，不直接写任何单课最终逐页稿。

### 单课定位

读取当前课程前后至少各一课；跨篇衔接时同时读取前一篇末课和后一篇首课。再检索164映射中本课全部代码，并检索核心关键词在其他课程的分布。

## 4. 课程边界卡

Checkpoint 1前必须给出或内部完成以下边界卡：

| 字段 | 必须回答 |
|---|---|
| 课程身份 | 第几篇、第几课、课程类型 |
| 核心问题 | 本课解决哪个真实导师问题 |
| 前课已经完成 | 已讲知识、已建模型、已有工具 |
| 本课必须讲 | 唯一主讲知识和不可替代能力 |
| 可以引用 | 可直接调用但不重新教学的模型、规则、工具 |
| 禁止展开 | 属于其他课或后课的内容 |
| 后课将继续 | 本课需要留下的接口 |
| 课程产出 | 学员完成的真实成果 |
| 去重风险 | 最容易与哪些课程重复及处理方式 |
| 删除测试 | 删除本课后会缺失什么能力 |

“必须讲／可以引用／禁止展开”必须具体到知识、方法或任务，不能只写主题名。

## 5. 课程设计方案

Checkpoint 1的课程设计方案至少包括：

1. 课程定位与边界卡
2. 学员现状和真实业务使用场景
3. 不可替代能力目标
4. 3—6个建议内容模块（不是固定数量）
5. 模块之间的学习递进
6. 计划形成的格知判断、案例或（确需时）工具产出——独立工具只在课表核心内容或用户明确要求时列入
7. 需要研究的关键事实与数据
8. 预判的重复风险、证据风险和教学难点
9. 暂不进入的内容

此阶段不写完整逐页稿。用户说“太理论”等反馈时，允许修改设计方案后再次确认。

## 6. Checkpoint 1

明确询问用户是否确认：

- 课程边界
- 能力目标
- 内容模块
- 研究方向
- 预计案例与工具

未确认前，不把试探性方案扩写成最终课程。

## 7. 研究与内容研发

确认后：

1. 建立研究问题清单。
2. 区分稳定知识与动态事实。
3. 形成证据卡与专家判断。
4. 设计普通学生和云南业务场景。
5. 设计案例、反例、工具、操作步骤和迁移任务。
6. 检查就业视角的权重是否适合当前篇章，而不是机械套用。
7. 形成完整课程内容蓝图。

## 8. 完整课程内容蓝图

蓝图是Checkpoint 2的中间确认稿，不是最终交付。至少包括：

- 课程定位、边界和能力目标
- 核心判断清单
- 每个判断的证据、条件和边界
- 内容模块与递进逻辑
- 反常识认知节点
- 真实案例及其教学任务
- 需要的模型、工具、清单或SOP（仅当课表核心内容或用户明确要求时列入；不为“贴近业务”增设课表外的表单或交付物）
- 普通学生、云南学生和家庭变量的体现方式
- 学员迁移任务
- 拟采用的PPT叙事顺序
- 预计动态数据与来源状态
- 暂不讲内容

不要求每课都有练习、作业、独立工具或总结；只保留对本课能力目标有贡献的设计。

## 9. Checkpoint 2

请用户确认课程内容是否进入逐页编排。重点确认：

- 判断是否成立
- 案例是否合适
- 工具是否可用
- 内容是否太浅或太理论
- 有无业务偏差
- 哪些内容需要删减、补充或调整

确认后才按 ppt-content-standard.md 输出最终逐页稿。

## 10. 篇章权重

不同篇章动态调整判断权重：

- 认知篇：职业身份、边界、服务责任、工具意识。
- 院校篇：院校资源、学科实力、培养机制、升学、就业、地域与行业积累。
- 专业篇：学习内容、能力结构、岗位、行业、学历门槛、就业与变化。
- 测评篇：学生兴趣、能力、性格、价值观、目标、家庭需求和风险边界。
- 政策篇：规则、资格、时间、口径、风险和年度变化。
- 途径篇：资格、培养、收益、约束、违约风险和学生适配。
- 实操篇：学生 × 家庭 × 学校 × 专业 × 城市 × 升学 × 就业 × 风险综合决策。
- 交付篇：沟通、解释、记录、审核、异常处理和完整服务责任。

就业倒推等模型在建立后可跨课调用，但不能每课重新讲一遍。
