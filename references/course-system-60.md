# 格知教育导师计划｜八篇60课正式课程总览

> 每个知识点仅有一个唯一主讲位置；后续课程只做引用、应用或案例训练。

# 01｜认知篇

## 第01课｜高考志愿规划师：职业定位与能力地图

- **核心问题：** 导师是谁、需要具备什么能力
- **原知识点：** RZ-01,RZ-02,RZ-03
- **核心内容：** 行业认知；规划师四种角色；七大核心能力；导师成长路径
- **课程产出：** 《格知导师能力地图》
- **课程类型：** 基础认知课
- **去重职责：** 职业认知只在本课讲透，后续不重复岗位定义

## 第02课｜格知导师职业规范与服务红线

- **核心问题：** 导师在服务中能做什么、不能做什么
- **原知识点：** RZ-04,RZ-09,RZ-10
- **核心内容：** 职业边界；不承诺录取；信息真实性；隐私保护；典型事故；格知工作原则
- **课程产出：** 《格知导师服务红线清单》
- **课程类型：** 基础认知课
- **去重职责：** 服务规范统一主讲，后续只执行

## 第03课｜高考志愿规划完整服务流程

- **核心问题：** 一名导师如何完成一次完整服务
- **原知识点：** RZ-05,RZ-06
- **核心内容：** 建档、访谈、定位、筛选、制表、讲解、填报、录取跟踪；四阶段时间安排
- **课程产出：** 《格知导师标准服务SOP》
- **课程类型：** 方法工具课
- **去重职责：** 流程只在本课建立，交付篇按流程演练

## 第04课｜导师工具体系与官方信息检索

- **核心问题：** 导师做规划需要哪些工具、去哪找可靠信息
- **原知识点：** RZ-07,RZ-08
- **核心内容：** 学生档案、访谈表、院校表、专业表、方案表、风险表；官方信息渠道
- **课程产出：** 《导师工具与信息源清单》
- **课程类型：** 方法工具课
- **去重职责：** 工具入口统一说明，后续直接使用

# 02｜院校篇

## 第05课｜中国高校体系与院校身份识别

- **原知识点：** YX-01,YX-02,YX-03,YX-04

- **课程类型：** 专题解析课
- **去重职责：** 院校身份只在本课讲，后续评价时直接调用

## 第07课｜城市、校区与大学培养机制

## 第08课｜学校、专业与城市：三维选择模型
