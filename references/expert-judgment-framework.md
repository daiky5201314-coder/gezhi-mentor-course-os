# 格知导师专家判断框架

## 1. 框架定位

本框架吸收原Skill中有价值的现实主义问题意识，但不是改名继承。每个模型都必须结合格知业务、60课体系、云南场景和当前招生就业环境重新验证。不适合现实的旧观点可以修改或放弃。

专家判断不是“信息越多越好”，而是把事实转化为有边界、可解释、可迁移的决策依据。

## 2. 标准判断链

重要观点尽量形成：

> 结论 → 证据 → 判断方法 → 适用条件 → 反例/边界 → 迁移方法

结论必须区分：

- 可以确认的事实
- 基于事实的专业推断
- 需要学生和家庭共同决定的价值选择
- 尚待核验的不确定项

## 3. 十个判断模型

### 3.1 职业出口倒推模型

职业/岗位 → 实际任务 → 核心能力 → 专业训练 → 院校资源 → 学历/资格门槛 → 行业与城市 → 学生/家庭适配。

用途：专业、院校和路径研究。边界：不能把所有选择简化为工资排序。

### 3.2 普通学生结果模型

同时观察头部、中位和尾部结果，重点追问普通院校、普通分数段、普通家庭能获得什么。识别“能进入”与“多数人能进入”的差别。

用途：修正名校、大厂、高薪和少数成功案例造成的样本偏差。

### 3.3 招聘证据链模型

合作宣传 → 实习 → 校招 → 岗位门槛 → 连续性 → 毕业生真实去向。企业行动比宣传口号更有判断价值。

用途：验证“就业好”“校企合作”“行业认可”。

### 3.4 学历与资格门槛模型

判断岗位是否有本科、硕士、博士、执业资格、学校层次或科研经历门槛；区分入行门槛、晋升门槛和头部岗位门槛。

用途：判断本科直接就业、考研必要性与长期成本。

### 3.5 院校资源可获得性模型

资源存在不等于学生能获得。检查资源层级、覆盖范围、选拔条件、进入概率和本科生实际受益。

用途：拆解一流专业、实验室、国际合作、推免和企业项目。

### 3.6 城市—产业—岗位耦合模型

城市价值取决于产业集群、岗位密度、实习机会、校友网络、生活成本和学生适配，不使用固定城市等级替代分析。

用途：比较留滇、出省和不同城市路径。

### 3.7 家庭支持与试错成本模型

分析预算、地域支持、信息能力、家庭资源、风险偏好和转换成本。不把家庭条件写成阶层宿命。

用途：评估长学制、考研、留学、异地发展和高风险路径。

### 3.8 不可替代性与转换成本模型

检查技能稀缺性、资格壁垒、经验积累、资源依赖、自动化风险和转行成本。

用途：行业变化与职业可持续性判断。边界：不可替代性不是静态标签。

### 3.9 风险—收益—可逆性模型

同时比较潜在收益、失败概率、最坏结果、补救路径、时间成本和选择可逆性。高收益不自动等于值得选择。

用途：调剂、特殊路径、长周期培养、行业波动和跨地域选择。

### 3.10 多时间尺度变化模型

分别观察大学四年、毕业初期、三至五年和更长期变化；考虑政策、技术、行业周期、学历扩张和家庭责任。

用途：避免用某一年的热门冷门直接预测终身。

## 4. 学生适配总框架

任何最终建议至少检查：

- 兴趣：愿不愿意长期投入
- 能力：课程和任务能否胜任
- 性格与价值观：工作方式、稳定性、意义、收入、地域偏好
- 学业基础：学科优势和学习方式
- 生涯目标：就业、深造、考公、体制、专业资格或多元路径
- 院校资源：学生实际能获得什么
- 专业训练：学什么、难点是什么
- 升学与就业：门槛、去向和普通结果
- 城市与地域：产业、机会、成本和家庭距离
- 家庭支持：预算、资源、风险承受与共识
- 时间变化：政策和行业未来可能如何变
- 风险与可逆性：失败后能否调整

## 5. 篇章调用规则

- 院校篇以院校资源、学科、培养、升学、就业和地域为中心。
- 专业篇以学习内容、能力、岗位、行业、学历门槛和就业为中心。
- 测评篇以学生本人和家庭需求为中心，不用就业模型压过学生画像。
- 政策篇以规则准确性、时效和风险为中心。
- 途径篇以资格、收益、约束和适配为中心。
- 实操篇才进行多变量综合决策。
- 交付篇以解释、沟通、审核和责任为中心。

一个模型如果已在前课建立，后课只调用其名称和必要步骤，不再次用数页重新教学。

## 6. 云南变量

优先关注云南考生、家庭、高校、招生、留滇与出省成本，以及教师、医疗、考公、央国企等高频场景。同时保持两条边界：

- 云南经验不能未经验证外推全国。
- 云南考生不等于应该留在云南。

最终判断仍由学生、家庭、院校、专业、城市、行业、升学、就业和风险共同决定。
